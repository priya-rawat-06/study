1. Executive Summary

Vibrant Study Planner & Prep Studio is a web application engineered to transform unstructured study materials into customized, actionable, and interactive learning trajectories. Powered by Google's Gemini 3.6 Flash model, the application generates day-by-day study schedules, structured Markdown notes, active recall flashcards, multiple-choice quizzes, and interactive AI tutoring.

This document outlines the complete architectural framework, full-stack directory organization, component inventory, step-by-step installation and execution procedures, API specifications, and the full development/troubleshooting log encountered during setup.

2. System Architecture & Tech Stack

The system utilizes a decoupled full-stack architecture separated into distinct client and server modules:

Layer Technologies Used Key Responsibilities
Frontend React 18, TypeScript, Vite, Tailwind CSS, Lucide React, Motion Renders interactive views (Schedule, Flashcard Trainer, Quiz Engine, Notes, AI Chat), manages user input, handles local client state.
Backend Node.js, Express.js, TypeScript (tsx), @google/genai, Dotenv Exposes secure RESTful API endpoints, constructs AI prompts, handles JSON schema enforcement, manages environment variables.
AI Engine Google Gemini 3.6 Flash API Generates structured study plans, generates flashcards/quizzes, streams interactive AI tutor responses.

4. Step-by-Step Instructions to Run the App

Step 1: Backend Setup & Execution

  1. Navigate to the backend directory:
    cd backend
  2. Ensure the .env file is present with your Gemini API key:
    GEMINI_API_KEY=your_gemini_api_key_here PORT=3000
  3. Install backend dependencies:
    npm install
  4. Start the backend server in development mode:
    npm run dev

    You will see the output: Server running at http://localhost:3000 (or http://127.0.0.1:3000)

Step 2: Frontend Setup & Execution

  1. Open a second terminal window and navigate to the frontend directory:
    cd frontend
  2. Verify the frontend package.json contains the correct dev script:
    { "scripts": { "dev": "vite", "build": "vite build", "preview": "vite preview" } }
  3. Install frontend dependencies:
    npm install
  4. Start the frontend development server:
    npm run dev

    Open your web browser and visit: http://localhost:5173

5. Core Feature Specifications

✨ AI Study Plan Generator

Uses Gemini 3.6 Flash with JSON Schema enforcement to create custom multi-day schedules based on target deadlines, study budgets (hours/day), and intensity preference.

🎴 Active Recall Flashcard Trainer

Provides flip animations, difficulty tracking (Easy/Medium/Hard), progress meters, and category filtering for high-retention review.

🧠 Interactive Quiz Engine

Generates multiple-choice practice quizzes complete with immediate feedback, detailed explanation breakdowns for correct answers, and final score summaries.

🤖 Real-time AI Tutor Chat

Embedded AI assistant allowing students to ask clarifying questions about specific study plan topics in real-time.

⏱️ Pomodoro Focus Timer

Built-in study timer supporting customizable focus cycles, short breaks, and long breaks with session count tracking.

6. Development & Troubleshooting Log

During the restructuring and execution process, the following key issues were identified and resolved:

Issue Description Root Cause Applied Resolution
'node_modules\.bin' is not recognized / TSX Missing Running npm run dev before running npm install in the backend directory on Windows. Ran npm install inside backend/ to link tsx CLI binaries properly.
Missing localhost server address output Console output logged raw binding address 0.0.0.0:3000. Updated server.ts log message to explicitly show http://localhost:3000.
Frontend failing with ERR_MODULE_NOT_FOUND (server.ts) Frontend package.json was copied directly from backend, so frontend npm run dev executed tsx server.ts. Updated frontend package.json script target to "dev": "vite".
Port Collision (EADDRINUSE: 0.0.0.0:3000) Attempting to launch backend when another Node.js process was already listening on port 3000. Terminated orphan Node processes (taskkill /F /IM node.exe) and configured Vite proxy on port 5173.
